# Independent Set: Споредба на класичен и SAT пристап

Овој проект прави експериментална споредба помеѓу директен **backtracking алгоритам** и два **SAT-базирани пристапи** за решавање на NP-комплетниот **Independent Set (Независно множество)** decision проблем.

Главната цел е да се испита како различните пристапи се однесуваат при промена на:

- големината на графот
- веројатноста за постоење на ребро
- бараната големина на независното множество

и кога SAT пристапот почнува да има практична предност во однос на директното пребарување.

---

## Опис на проблемот

Даден е неориентиран граф:

```text
G = (V, E)
```

и цел број `k`.

Decision верзијата на Independent Set проблемот го поставува прашањето:

> Дали постои подмножество `S ⊆ V` со најмалку `k` темиња, такво што ниту еден пар темиња од `S` не е поврзан со ребро?

Independent Set е NP-комплетен проблем.

Во имплементацијата, темињата на граф со `n` темиња се претставени со:

```text
0, 1, ..., n - 1
```

---

# Имплементирани пристапи

Во проектот се споредуваат три методи.

## 1. Backtracking

Имплементиран е директен рекурзивен backtracking алгоритам.

При обид да се додаде ново теме во моменталното решение, алгоритмот проверува само дали новото теме е соседно со некое од веќе избраните темиња.

На овој начин не се извршува повторна целосна валидација на истото парцијално решение при секој рекурзивен чекор.

За потешките инстанци е поставен временски лимит од:

```text
10 секунди
```

Timeout се третира одделно од математички невалидно решение.

---

## 2. MiniSat

Independent Set проблемот се редуцира во SAT проблем во CNF форма.

Добиената CNF формула се решава со **MiniSat 2.2** преку библиотеката PySAT.

---

## 3. CaDiCaL

Истата CNF формула се решава и со **CaDiCaL** преку PySAT.

MiniSat и CaDiCaL добиваат **иста SAT енкодирана формула**, со што споредбата помеѓу двата SAT решавачи е методолошки конзистентна.

---

# SAT енкодирање

За секое теме `v` се дефинира Булова променлива која означува дали темето е избрано во независното множество.

Бидејќи DIMACS/SAT променливите започнуваат од 1:

```text
SAT variable 1  <-> vertex 0
SAT variable 2  <-> vertex 1
...
SAT variable n  <-> vertex n - 1
```

## Ограничување за независност

За секое ребро `(u, v)` се додава клаузулата:

```text
¬x_u ∨ ¬x_v
```

Со ова се гарантира дека две соседни темиња не можат истовремено да бидат избрани.

## AtLeastK ограничување

Потребно е:

```text
Σ x_i >= k
```

За cardinality ограничувањето се користи PySAT `CardEnc.atleast` со експлицитно избран **sequential-counter encoding**.

Енкодирањето може да воведе дополнителни помошни SAT променливи. Оригиналните променливи `1..n` остануваат резервирани за темињата на графот, а помошните променливи добиваат поголеми идентификатори.

При реконструкција на Independent Set решението се разгледуваат само оригиналните `n` променливи.

---

# Генерирање на графови

Графовите се генерираат според случајниот модел:

```text
G(n, p)
```

За секој можен неориентиран раб `(u, v)`, каде `u < v`, работ независно се додава со веројатност `p`.

Затоа `p` претставува **edge-generation probability**, а не нужно точната реализирана густина на конкретниот генериран граф.

За репродуктивност се користи зададен `seed`.

Генераторот користи локална random состојба, така што генерирањето на граф не ја менува глобалната random состојба на програмата.

# Експериментална поставеност

Во финалните експерименти се користат:

```text
n = 20, 30, 40, 50, 60

p = 0.2, 0.5, 0.8

seeds = 1, 2, 3

k/n = 0.3, 0.4
```

За дадените конфигурации се пресметува:

```python
k = max(1, int(n * k_ratio))
```

Со комбинација на параметрите се добиваат:

```text
5 × 3 × 3 × 2 = 90
```

различни експериментални инстанци.

За секоја инстанца се извршуваат:

- Backtracking
- MiniSat
- CaDiCaL

Со тоа финалниот CSV содржи:

```text
90 × 3 = 270 редови
```

# Мерење на времето

Секое мерење се повторува:

```text
5 пати
```

а како репрезентативна вредност се користи **медијаната**.

За backtracking е поставен timeout од:

```text
10 секунди
```

Ако алгоритмот го достигне timeout-от, тој случај се бележи посебно и не се третира како математички невалидно решение.

За SAT пристапот се следат:

- `encoding_time`
- `solver_time`
- `total_time`
- број на CNF променливи
- број на CNF клаузули

`encoding_time` се мери одделно од фазата на повикување на SAT решавачот.

`total_time` претставува комбинација од времето за енкодирање и времето на SAT solver фазата.

---

# Валидација на решенијата

Решавачите се одделени од валидаторот.

Архитектурата е:

```text
solver
  ↓
candidate solution
  ↓
validator
```

Валидаторот независно проверува дали вратеното решение:

- има најмалку `k` темиња
- не содржи дупликати
- содржи валидни темиња од графот
- не содржи две соседни темиња

Валидацијата се извршува над завршеното решение и не е дел од мереното време на самиот solver.

# Заклучок

Експериментите покажуваат јасна разлика помеѓу директното комбинаторно пребарување и SAT редукцијата.

Backtracking има многу мал overhead и може да биде најбрз кај мали или лесно pruning-погодни инстанци.

Со зголемување на големината и тежината на инстанците, SAT пристапот покажува значително подобро скалирање.

Резултатите исто така покажуваат дека структурата на графот има големо влијание врз backtracking пребарувањето: поретките графови оставаат поголем простор на можни кандидати, додека погустите графови овозможуваат порано отсекување на гранките.

Проектот со тоа демонстрира не само коректна редукција на Independent Set во SAT, туку и практична експериментална споредба на два различни начини за решавање на ист NP-комплетен decision проблем.
