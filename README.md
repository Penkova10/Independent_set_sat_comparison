# Independent Set: Споредба на класичен и SAT пристап

Овој проект прави експериментална споредба помеѓу класичен backtracking алгоритам и SAT-базирани пристапи за решавање на **Independent Set (Независно множество)** проблемот.

Главната цел е да се испита кога класичниот алгоритам е поефикасен, а кога користењето SAT решавачи има предност.

## Опис на проблемот

Даден е неориентиран граф:

G = (V, E)

и цел број `k`.

Decision верзијата на Independent Set проблемот го поставува прашањето:

> Дали постои подмножество S од V со најмалку k темиња, такво што ниту еден пар темиња од S не е поврзан со ребро?

Independent Set е NP-комплетен проблем.

## Имплементирани пристапи

Во проектот се споредуваат три пристапи:

### 1. Backtracking

Имплементиран е класичен рекурзивен backtracking алгоритам кој пребарува дали постои независно множество со големина најмалку `k`.

За потешките инстанци е поставен временски лимит од 10 секунди.

### 2. MiniSat

Independent Set проблемот се трансформира во SAT проблем во CNF форма, по што добиената формула се решава со MiniSat преку PySAT.

### 3. CaDiCaL

Истата SAT формула се решава и со CaDiCaL, со што се овозможува споредба помеѓу два различни SAT решавачи.

## SAT енкодирање

За секое теме `v` се дефинира Булова променлива `x_v` која означува дали темето припаѓа на независното множество.

За секое ребро `(u, v)` се додава клаузулата:

```text
¬x_u ∨ ¬x_v
```

Со ова се гарантира дека две соседни темиња не можат истовремено да бидат избрани во независното множество.

Дополнително се додава cardinality ограничување со кое се бара да бидат избрани најмалку `k` темиња.

## Експериментална поставеност

За тестирање автоматски се генерираат случајни графови со различни:

- броеви на темиња
- веројатности за постоење на ребро
- random seed вредности
- барани големини на независното множество

Во финалните експерименти се користат:

```text
n = 20, 30, 40, 50, 60
p = 0.2, 0.5, 0.8
seeds = 1, 2, 3
k/n = 0.3, 0.4
```

Со комбинација на овие параметри се добиваат вкупно **90 различни инстанци**.

Секое мерење на времето се повторува 5 пати, а како финална вредност се користи медијаната.

За backtracking алгоритмот е поставен временски лимит од 10 секунди.

За SAT пристапите се мерат:

- време потребно за SAT енкодирање
- време потребно за решавање
- вкупно време
- број на CNF променливи
- број на CNF клаузули

Дополнително, добиените решенија се проверуваат со посебен валидатор.

## Резултати

Експериментите покажуваат дека перформансите зависат од големината и густината на графот.

Кај мали или поволни инстанци класичниот backtracking пристап може да биде конкурентен или побрз, бидејќи нема дополнителен трошок за SAT енкодирање и повикување на SAT решавач.

Со зголемување на големината и тежината на проблемот, SAT пристапот станува значително поефикасен.

Во спроведените експерименти ретките графови се покажаа како особено тешки за backtracking алгоритмот, додека SAT решавачите ефикасно ги решаваа истите инстанци.

Кај дел од најтешките инстанци backtracking алгоритмот го достигнува временскиот лимит од 10 секунди.

Деталните резултати од финалните експерименти се наоѓаат во:

```text
results/final_results.csv
```

Генерираните графици се наоѓаат во:

```text
results/plots/
```

## Инсталација

Потребен е Python 3.

По преземање на проектот, потребните библиотеки се инсталираат со:

```bash
pip install -r requirements.txt
```

## Стартување на проектот

Проектот се стартува со:

```bash
python main.py
```

Програмата ги извршува конфигурираните експерименти, ги зачувува резултатите во CSV, ја извршува статистичката анализа и ги генерира графиците.
